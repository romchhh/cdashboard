Як рахуються статуси Fast / Medium / Slow / Dead?
  • База: середній продаж/день за останні {{ basis }} дн (з історії продажів у БД).
  • Fast: ≥ {{ '%.2f'|format(fast_thr) }} шт/день.
  • Medium: від {{ '%.2f'|format(med_thr) }} до < {{ '%.2f'|format(fast_thr) }} шт/день.
  • Slow: є продажі, але нижче medium; або ≥ {{ slow_d }} дн. підряд без продажів.
  • Dead Stock: без продажів ≥ {{ dead_d }} дн. (є залишок).
  • Нові: менше 7 записів денної історії в БД.
  • Немає в наявності: залишок 0 у фіді.

Пороги змінюються в налаштуваннях. На сторінці «За статусами руху» ті самі правила, але перерахунок за обраним горизонтом — цифри можуть відрізнятися.
