Статуси товарів

За якими даними рахуються статуси

  • Fast: середній продаж/день за {{ basis }} дн ≥ {{ '%.2f'|format(fast_thr) }} шт/день.
  • Medium: від {{ '%.2f'|format(med_thr) }} до < {{ '%.2f'|format(fast_thr) }} шт/день.
  • Slow (за «застоєм»): менше {{ '%.2f'|format(med_thr) }} шт/день або ≥ {{ slow_d }} дн. підряд без продажів.
  • Dead Stock: без продажів ≥ {{ dead_d }} дн.
  • Нові: менше {{ hist_rec }} записів денної історії в БД.
  • Немає в наявності: залишок 0 у фіді.

Пороги змінюються в налаштуваннях закупівель.

Як працює система статусів?

Fast Movers

Бестселери: середній продаж за {{ basis }} дн ≥ {{ '%.2f'|format(fast_thr) }} шт/день. Важливо тримати в наявності.

Medium Movers

Стабільні продажі середнього темпу: від {{ '%.2f'|format(med_thr) }} до < {{ '%.2f'|format(fast_thr) }} шт/день. Закуповувати планово.

Slow Movers

Менше {{ '%.2f'|format(med_thr) }} шт/день або {{ slow_d }}+ днів підряд без продажів. Закуповувати обережно.

Dead Stock

Неліквід: без продажів {{ dead_d }}+ днів. Рекомендується розпродаж для вивільнення капіталу.

Нові

Менше {{ hist_rec }} записів денної історії продажів у БД — недостатньо даних для стійкої оцінки швидкості.

Немає в наявності

Товар закінчився на складі. Якщо це Fast або Medium Mover — терміново закупити.
