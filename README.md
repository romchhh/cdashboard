# CosmyFinancesBot — Telegram Bot для фінансового обліку

Автоматизована система фінансового обліку через Telegram-бот з інтеграцією Monobank та NovaPay.

**Повна документація по модулях:** [docs/README.md](docs/README.md)  
**JSON-конфіги (маркетинг, GSC, пороги):** [settings/README.md](settings/README.md)

## 🚀 Швидкий старт

1. **Встановити залежності:**
```bash
pip install -r requirements.txt
```

2. **Налаштувати `.env`:**
```env
# Telegram
TELEGRAM_BOT_TOKEN=your_bot_token_here
ADMIN_USER_IDS=123456789,987654321  # Через кому

# Database (опціонально)
DATABASE_URL=sqlite+aiosqlite:///./databases/finance_bot.db
```

3. **Запустити бота:**
```bash
python main.py
# або
python main_bot.py
```

### Веб-апка (FastAPI)

Окремо від бота можна запустити веб-інтерфейс з тим самим функціоналом (баланси, звіти, транзакції, непідтверджені, синхронізація). Логін і пароль — у `.env`.

**Опційно в `.env`:**
```env
WEB_USERNAME=admin
WEB_PASSWORD=your_password
WEB_SECRET_KEY=random-secret-for-sessions
```

**Запуск веб-апки:**
```bash
pip install -r requirements.txt   # якщо ще не встановлено
./start.sh
# перезапуск: ./restart.sh
```

Відкрити в браузері: **http://localhost:8000** → сторінка логіну → після входу: головна (баланси), звіти, транзакції, непідтверджені, синхронізація.

## 🤖 Функціонал бота

### Головне меню
- 📊 **Звіти** — Cashflow, P&L, розбивка, порівняння
- 💳 **Транзакції** — перегляд, фільтри, підтвердження
- ⚙️ **Налаштування** — ФОПи, категорії, бюджети
- 🔔 **Сповіщення** — щоденні звіти, алерти

### Команди
```
/start          - Головне меню з балансами (з БД)
/balance        - Оновити баланси з API
/today          - Транзакції за сьогодні
/week           - За тиждень
/month          - За місяць
/pending        - Непідтверджені транзакції
/cashflow       - Грошовий потік за місяць
/pl             - Прибутки і збитки (P&L)
/breakdown      - Розбивка витрат по категоріях
/compare        - Порівняння періодів
/balances_db    - Баланси з БД (історія)
/balance_history - Історія балансів за 7 днів
/balance_trend  - Тренд балансів (порівняння)
```

### Автоматизація (Cron-задачі)

| Задача | Частота | Опис |
|--------|---------|------|
| Синхронізація транзакцій | Кожні 15 хв | Завантажує транзакції з Mono/Nova за 7 днів |
| Синхронізація балансів | Кожні 30 хв | Зберігає знімки балансів в БД |
| Оновлення токенів NovaPay | Кожні 12 год | Оновлює principal для всіх користувачів |
| Щоденний звіт | 09:00 щодня | Надсилає звіт за вчора адмінам |
| Перевірка непідтверджених | Кожну годину | Сповіщення про pending транзакції |

### Автокласифікація транзакцій

**3-рівнева система:**
1. Точне співпадіння контрагента → 100% впевненість → автопідтвердження
2. Ключові слова з БД (навчена) → 70-100%
3. Дефолтні правила → 80% (Google Ads, Meta, Податки, тощо)

Якщо впевненість < 90% → транзакція потребує підтвердження через inline-кнопки.

## 🗄️ База даних

### Основні таблиці
- **fops** — ФОП підприємці
- **categories** — категорії витрат/доходів
- **transactions** — всі транзакції
- **account_balances** — історія балансів (snapshots)
- **classification_rules** — правила автокласифікації
- **budgets** — бюджети по категоріях
- **notification_settings** — налаштування сповіщень
